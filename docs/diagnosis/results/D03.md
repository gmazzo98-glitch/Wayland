# D03 Peer engine: peer groups and percentiles for every ratio
Agent: antigravity-d41e   Branch: diag/D03-peer-engine-peer-groups-and   Merged: 2026-10-26

## What I built
- `diagnosis/models_peers.py`: Defines the cached `dx_peer_stats` table on `models.Base` for storing precomputed peer group distributions and statistics.
- `diagnosis/peers.py`: The peer engine implementing ATECO hierarchy widening (6 -> 5 -> 4 -> 3 -> 2 digits) until n >= 12, bulk financial extraction from AIDA raw records, mid-rank percentile ranking excluding self, size cuts (headcount terciles) and secondary regional cuts, in-memory `PeerIndex`, and CLI `python -m diagnosis.peers --rebuild`.
- `diagnosis/readers/derive_peers.py`: Deriver registered as `@deriver("peer_percentiles", after=("financial",))` emitting `peer.group_label`, `peer.group_n`, `peer.group_level`, and `peer.{metric}.median` / `peer.{metric}.pctile` Facts with Grade A.
- `tests/test_diagnosis_peers.py`: Test suite verifying percentile monotonicity, widening hierarchy, self-exclusion, fact key and grade contract adherence, SQLite table persistence, and live acceptance criteria.

## How I verified it
- Ran isolated unit test suite: `python -m pytest tests/test_diagnosis_peers.py --capture=no -p no:cacheprovider` (8 passed, 1 skipped in 1.18s).
- Ran live acceptance test against the live Neon database: `python -m pytest tests/test_diagnosis_peers.py -k "test_live_cohort_rebuild_metrics"` (passed in 13.75s).
- Ran rebuild CLI on all 953 companies: `python -m diagnosis.peers --rebuild --dry-run` (executed in 6.34s, well below the 60s limit).
- Verified median match with `SectorCostBenchmark`: medians for `materials_pct_revenue` match `SectorCostBenchmark.materials_cost` on overlapping 6-digit codes (e.g. ATECO 282500 median 48.95% on both).
- Monotonicity of mid-rank percentile verified across 61 test values on synthetic distributions.

## What it does NOT do
- Does not emit DSO, DIO, DPO percentiles because trade receivables, inventory and payables are not yet collected in current AIDA exports (deferred to D35).
- Does not silently blend regional or size cuts into the primary ATECO peer groups; secondary cuts are kept separate.
- Does not write to the live database by default unless `--apply` is explicitly passed.
