# I11 — Document reader: certificates, manuals, brochures, annual reports

## What I built

- `intel/pdf.py` — parsing helpers over the PDF text the fetcher already extracts: `classify_document`
  (certificate / manual / report / policy / other / scanned), `extract_certificate` (standard, number,
  issuing body, issue/expiry dates from the text, or the standard + validity date from the file name
  when the text layer is masked — many certificates mask fields with `********` or are pure scans),
  `extract_manual` (family code, e.g. IOMS-style), `extract_report` (year, revenue/employees/EBITDA
  from the first pages only), `select_pages` (a bounded, keyword-aware excerpt so a 200-page report
  is never read whole). No OCR: a PDF without a text layer is reported as "scanned, not read".
- `intel/collectors/documents.py` — the `documents` collector (produces `documents.`,
  `certifications.`, `products.`, `financials.`; requires web only, no LLM, cost per document = one
  fetch + a bounded excerpt). Finds the download area WITHOUT path guessing: homepage navigation
  links whose URL names documents/downloads/certifications (in it/en), including off-site document
  URLs (Corrada's PDFs live on a CDN subdomain); when no such page exists it follows quality /
  sustainability / certification pages once each (Emmegi publishes its certificates there); then
  reads each PDF link. Emits `documents.published` (count by kind), `documents.item` (one per
  document), `certifications.claimed` (standard, issuer, expiry, document URL — grade B, the
  on-ramp for I15's register lookups), `certifications.expired_flag` (validity in the past: grade D,
  0.5 confidence, "check for renewal"), `products.manual` (family code + title), `financials.report`
  (year + headline figures, first pages). Honest absence: `documents.item` checked_absent when the
  site publishes no PDFs after a real search; every scanned/unreadable PDF is reported, never skipped.
- `tests/test_intel_documents.py` — 13 offline tests with recorded pages (no network): parsing
  (dates from text and from file names, module H vs H1, manual family code, report figures, page
  selection bounds), collector behaviour (discovery, quote grounding, scanned handling, honest
  absence, no hard-coded golden company, registration).

## Decisions taken and why

- **No OCR.** pypdf's text layer covers every certificate tested except two scans; tesseract is not
  a repo dependency and the ticket allows "mark scanned, not read". Recorded as such, per document.
- **File-name dates and standards are used only when the text layer is masked or absent**, and the
  fact carries `date_source: "file_name"` so I15 and the dossier can treat it as weaker. The
  evidence quote for scanned documents is the file name with an explicit note; the collector logs
  "document fact without a text quote" so the audit can find them.
- **`certifications.claimed` is grade B by design** (the company's own certificate PDF); I15 owns
  register verification and the upgrade to grade A. `expired_flag` is grade D / 0.5 (inference from
  a date, never a judgement presented as fact).
- **Off-site document pages are followed only when the link itself names documents/downloads**
  (Corrada/eglagroup case); generic off-site links are still ignored, so the crawler cannot wander.
- **Hint pages (quality/sustainability/certifications)** are followed only when no explicit
  documents URL exists in the navigation — one fetch each, capped at 6, discovered links only.
- No gg_input/gg_approval needs applied to this ticket; G-decisions untouched.

## Not done / open points

- `products.manual` family codes come from the document text; on ASCO one manual (SCT) yields
  `IOM-SCT-001` (the PDF's own typo: "IOM" without the S) — stored verbatim, as the document says.
- Reports: only `financials.report` headline figures from the first pages; deep report reading
  (multi-year tables) is left to I10's digest and the orchestrator.
- The 6 MB fetch cap and 40-document cap bound the cost; a site with hundreds of PDFs is sampled,
  not exhausted (not yet needed by any golden company).
- Corrada's parent-group downloads are attributed to the company via the listing page link; the
  ownership-aware split (which PDF belongs to which group entity) needs I12's group facts.
