# I18: Technology and digital footprint v2 (extends the header collector; ledger only, no signal changes)

*Done 2026-10-27 by claude-0625. Branch `intel/I18-technology-and-digital-footprint`. Write scope: `intel/collectors/site_headers.py`, `intel/collectors/tech_stack.py`, `tests/test_intel_tech_stack.py`, this note. Three files outside it were touched, each for a stated reason (see "Decisions").*

## What I built

- `intel/collectors/site_headers.py` (extended, collector `site-headers`): besides server, framework, CMS, hosting panel and e-commerce headers it now reads
  * the CDN or protection layer (Cloudflare, CloudFront, Akamai, Fastly, Azure Front Door, Vercel, Netlify, Imperva, Sucuri, GitHub Pages) -> `digital.cdn`;
  * the application framework from session-cookie NAMES (PHPSESSID, ASP.NET_SessionId, JSESSIONID, laravel_session ...; never the cookie value) -> `digital.web_framework`;
  * `X-Powered-By: PHP/8.3.36, PleskLin` is split into a framework fact and a hosting-panel fact;
  * server software past its vendor's end of support (PHP, Apache httpd, IIS, OpenSSL; dated table in the file, reviewed 2026-10-27, to be reviewed yearly) -> `digital.outdated_software`;
  * the six security headers (HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy) -> `digital.security_headers` ("3 of 6 present: ...; missing: ..."; a CSP that allows any script source plus inline scripts is called permissive) and `digital.hsts`;
  * the TLS certificate (one handshake to the company's own server): issuer, protocol, expiry -> `digital.tls_certificate`; an untrusted, expired or about-to-expire certificate, or an https fetch that failed with a certificate error, -> `digital.tls_problem`;
  * https failing for a transport reason falls back once to plain http, so the rest of the footprint can still be read (`fetch_homepage`).
  It also holds the helpers both collectors share: `FactSink` (checks that each quote really occurs in the fetched text, then passes EVERY fact through `intel/verify.py`, drops a "rejected" verdict and reports it) and `fetch_homepage`.
- `intel/collectors/tech_stack.py` (new, collector `tech-stack`): reads the homepage and a bounded sample (at most 12) of the internal pages the homepage itself links to (never guessed paths; informative paths first), then three public lookups. Facts, all under `digital.`:
  * technologies: `cms`, `ecommerce_platform`, `js_framework` (jQuery and Bootstrap with version when the file name or query string has it), `analytics`, `tag_manager` (container id), `advertising_tags`, `marketing_automation`, `crm`, `lead_intelligence` (B2B visitor identification), `live_chat`, `cookie_consent`, `cad_portal` (CADENAS, TraceParts), `product_3d_viewer`, `configurator` (CPQ vendors and "configuratore" links), `customer_portal` (reserved area, portal sub-domain of the company's own domain), `support_portal`, `iot_platform`, `quote_request`, `web_agency` (meta author or footer credit). 127 original signatures.
  * `outdated_software`: jQuery below 3.5.0, Bootstrap 3 and 4, AngularJS, Flash content, a Universal Analytics tag with nothing modern beside it.
  * `quality_issue`: placeholder or template text (alt attributes, lorem ipsum, default WordPress/IIS/nginx/Apache pages, example e-mail addresses), statistic counters that ship as 0, broken internal links (HTTP 404 or 410 only), a stale footer copyright year, template demo files still linked, a homepage set to noindex, mixed-language pages. Each says where (path) and quotes the markup.
  * `site_language` (html lang and hreflang, real ISO codes only), `social_<network>` (LinkedIn, Facebook, Instagram, YouTube, X, Xing, TikTok: the accounts the site links or declares in JSON-LD `sameAs`; share buttons ignored).
  * `domain_registered_on` (RDAP, grade A), `wayback_first_seen` (Internet Archive CDX, grade C), `site_redirect` (the configured address answers from another registrable domain). The two domain facts follow the CONFIGURED domain and carry a second Evidence: the homepage sentence naming the company, which is why the domain is attributed to it; no homepage sentence naming the company, no domain facts.
- `intel/fetch.py` (additive): `Page.raw` (decoded markup or API body, capped at 600,000 characters; HTML, JSON and XML) and `PoliteFetcher.network_probes = True` (a fetcher that talks to the real internet; collectors make a direct probe such as the TLS handshake only when the fetcher declares it, so recorded-page test doubles never touch the network).
- `tests/test_intel_tech_stack.py`: 41 offline tests on recorded, synthetic pages (signatures and look-alike words, outdated software, each quality check, social, link picking, the collector end to end, the gate being called once per fact and a rejected verdict dropping the fact, domain facts and their second evidence, redirect, RDAP 404, TLS paths with a monkeypatched probe, `Page.raw`).
- `tests/test_intel_no_golden_leak.py`: deleted the line `intel/collectors/site_headers.py: I18` from `ALLOWED_UNTIL_FIXED` (my docstring example is reworded), as the test's own contract and the coordinator require; no line added.

8. The verification gate read the raw markup as page text, so any brand in an asset path "named the company". Fixed: the gate reads the grounded quote plus the homepage's visible text (test: a site that names someone else leaves every fact unverified).

## Decisions taken and why

- **No community technology database imported.** Checked 2026-10-27: `enthec/webappanalyzer` (the community successor of Wappalyzer) is GPL-3.0; the original `AliasIO/wappalyzer` repository is gone (404). Importing GPL data into this repository would carry copyleft. The 127 signatures are original, written from how each product announces itself; a new one is one `Sig(...)` line plus a test.
- **RDAP only where it exists.** The IANA bootstrap has no RDAP service for `.it`, `.de`, `.eu`, `.ch`, `.at` (checked); `rdap.org` answers 404 for them. Those companies get "no RDAP record: unknown, not absent" and the Internet Archive first capture as the domain-age proxy. WHOIS on port 43 was not used (rate limits and acceptable-use terms of the registries).
- **YouTube "last public activity" not built.** The channel feed (`/feeds/videos.xml`) is disallowed for every agent in YouTube's robots.txt (checked), the fetcher correctly refuses it, and the other networks sit behind login walls (decision G2: public pages only). Social accounts are inventoried; their activity is unknown, not absent. No code, no fact.
- **Quality checks are observations with their quote, not scores.** Two are estimates and are low-confidence and unverified on purpose (counters, mixed language). `tech_stack_intensity` and every signal are untouched (I35).
- **Facts about a domain are attributed to the company only through a homepage sentence that names it** (second Evidence). A homepage that names nobody gets no domain facts; a technology fact from such a site is emitted but unverified.
- **Files outside the write scope, and why:** (1) `intel/fetch.py`, additive: markup fingerprinting and API quoting need the body as served, which `Page.text` (scripts and attributes stripped) cannot give; no other claimed ticket owns the file, I05 is DONE. (2) `tests/test_intel_no_golden_leak.py`: delete my own allowlist line, mandated by the test and by the coordinator. (3) `docs/intel/results/I18.md` and the status file line are mine by protocol.
- **Direct network probe only for a fetcher that says so (`network_probes`).** The TLS handshake is not a page fetch, so it cannot go through `ctx.fetch`; the flag keeps every recorded-page test off the network.

## Not done / open points

- Social last-activity (see above); typos; mixed-language is an estimate; no LLM was used (the ticket needs none).
- False-negative rate unmeasured (technology inside bundled scripts, sites that render everything client-side: `Page.raw` then holds only the shell; the browser fallback exists in the fetcher, off by default).
- Signature set is a starting set (127). Industrial customer-portal and IoT detection is link- and host-pattern based and found nothing on the ten sites read; it is proven only by unit tests, not by a live positive.
- The EOL table (PHP, IIS, Apache, OpenSSL) and the jQuery / Bootstrap / AngularJS / Universal Analytics dates need a yearly review.
- The hold-out companies were not run; a 30-fact precision audit on three companies per the program target is for the release captain.
