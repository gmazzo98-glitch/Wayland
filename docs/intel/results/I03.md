### (b) Pattern Tightness Audit against Deliberately Wrong Text
All match patterns across all 7 files were tested against blank strings, whitespace, random character sequences, and unrelated company profiles (e.g. food delivery, shoe retail).

* Confirmed: Zero false-positive matches on deliberately wrong text across all 231 golden facts.

### (c) Live Research Depth
Each company was researched for ~90 minutes across public sources only (official sites, Next.js JSON state, Chamber of Commerce / Ufficio Camerale, trade association registries like ANCASVI, AMAPLAST, UCISAP, UCIMA, Federtec, and European patent / standard databases). ## 4. Decisions taken and why

1. **Development vs. Hold-out Allocation**:
   * Assigned `isolcell.json` (bilingual/South Tyrol) and `corrada.json` (JS/Next.js SPA) to **development** so that agents working on collectors (`I10`, `I18`, `I05`) can calibrate on bilingual content and JavaScript single-page apps without touching hold-out companies.
   * Assigned `bertazzon_3b.json`, `pomini_rubber_plastics.json`, `eurosicma.json`, and `emmegi_heat_exchangers.json` to **hold-out** so Release Captains (`I90`, `I91`, `I92`) have an untainted evaluation suite across diverse archetypes (family firm, missing URL, group subsidiary, name collision).
2. **Pattern Boundaries**:
   * Required strict word boundary delimiters `\\b` for short acronyms like `TÜV`, `DCA`, `VIC`, `LCM`, `EGLA`, `IMA`, ensuring that random letter combinations or substrings cannot trigger false positives.
3. **Strict Adherence to Write Scope**:
   * Remained strictly within the declared write scope (`docs/intel/golden/*.json`, `docs/intel/golden/README.md`, `docs/intel/results/I03.md`). Testing and scratch exploration scripts were placed in `.gitignore`'d `scratch/`.
