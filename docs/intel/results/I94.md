## Decisions taken and why
* Created I94 instead of editing a DONE ticket (the board has no DONE to OPEN path; the prompt says problems become tickets).
* Kept the original six companies (they cover the archetypes) and rebuilt their facts rather than replacing them; AIDA-derived facts stay (source `AIDA export held in the tool`, the same convention as ASCO) but each carries a quote checked against the database text.
* Grade D "targeting consequence" facts use patterns that only match a stated consequence ("controlled subsidiary", "personal holding", "name collision"), never the raw data, so a tool cannot "hold" them by holding shareholders.
* Facts that carry two dates or two capital figures (founded 1958 vs incorporated 1983, EUR 4M vs 2M capital) record the conflict instead of picking one.
* Where a site cannot be read without rendering (HF Group), archived copies were used and said so.
* Emmegi/Isolcell ATECO patterns are anchored to the company name: an ATECO code alone is shared by every company with that code and would fail the hostile-text test.
