# I01: Golden benchmark and gap scorer (ASCO Filtri). DONE by claude-code-founder, 2026-10-27

## What I built
* `docs/intel/golden/asco_filtri.json`: 42 facts a human found about ASCO Filtri S.p.A. with a browser and public APIs, each with sources, a grade (A/B/C/D), a weight (3 decisive to 1 useful), a regex check (`match`) and the tickets that must close it (`closed_by`).
* `scripts/intel_gap.py`: reads the database (read-only), a `scripts/crawler_bench.py` report, or an `intel_run.py` output, and reports weighted coverage per category, the misses, and `--require-ticket` / `--min-coverage` exit codes. `--web-only` drops registry/AIDA text so it measures the collection layer alone.
* `tests/test_intel_gap.py`.

## Verified live
Research (all public sources, no paid database): ASCO's own site and headers, Atoka and Top Aziende public pages, PR Newswire (Mott, 13 Jan 2022), BeBeez (Red-Fish Kapital, July 2019), Filtsep and Hartford Business (IDEX buys Mott), SEC EDGAR full-text (IDEX FY2024 and FY2025 10-K Exhibit 21 lists "Asco Filtri SpA"), the IPCEI Hydrogen directory, GLEIF (LEIs exist for ASCO and Mott, parent relationships do not), a Google News RSS probe. Then the tool: live database read, and `scripts/crawler_bench.py --lanes all` on ASCO into a throwaway SQLite file (about 6 minutes).

## Golden score before / after
Baseline: **11 of 42 facts held, 23% weighted** (live database, everything); **2 of 42, 3%** from the crawlers and web layer; a fresh bench run also 2 of 42. After I02's reference collector: DG-02 (IIS / ASP.NET) is captured by the new ledger collector.

## Decisions taken and why
* A capture is a regex hit in the text the tool stored; it proves the tool *holds* a fact, not that it is shown or correct. Acceptance in every ticket therefore adds human checks.
* Three of my own first patterns were too loose and were caught by reading what the scorer reported as captured: `samp` matched "sample", `mott` plus `2022` matched an unrelated appointment date, `17.14` matched any float. They are tightened and pinned by `test_shipped_patterns_stay_tight`. A pattern edit is a code change; review it.
* The input company block in an `intel_run.py` output is excluded from scoring, otherwise the VAT and city we start from would count as findings.
* AIDA already holds ASCO's control chain (Mott level 1, IDEX level 2), so ownership facts OW-01 and OW-03 are not collection gaps; the gap is that nothing flags it (OW-06, ticket I12 / I42).
