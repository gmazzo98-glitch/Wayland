# I15 — Certification and compliance register lookups (Accredia, notified bodies, ASME, Achilles)

Agent: `vibe-a3f7` · branch `intel/I15-certification-and-compliance` · write scope: `intel/collectors/certifications.py`, `tests/test_intel_certifications.py`, `docs/intel/results/I15.md`

## What I built

- `intel/collectors/certifications.py` — the `certifications` collector. Crawls the company's own site (homepage as hub; quality-hinted pages deepened; a redirect to the group's domain, e.g. corrada.it → eglagroup.com, is accepted as the company's own presentation and its final host allowed once discovered), scans page text and the certificate PDFs linked from it, and emits quote-grounded grade-B facts under `certifications.iso_management`, `certifications.product_or_scheme`, `certifications.third_party_audit`, `certifications.supplier_register`. Certificate PDF **file names** contribute scheme + expiry tokens (e.g. `ISO_9001-...-20260629.pdf`) only when the scheme token also occurs in the visible page text — the href itself is not page text and cannot be the quote. A scanned/image-only PDF (empty text) yields **no** fact and an honest error. `checked_absent` is recorded per key when the site was read and nothing matched that key.
- `tests/test_intel_certifications.py` — 8 offline tests with recorded pages (no network): PDF-href scheme+expiry capture, page-text scan, scanned-PDF-no-fact, full and partial `checked_absent`, no-website error, ledger validation + `quote_in_text` grounding of every emitted fact, prefix discipline, registry discovery.

## Feasibility table (probed live 2026-10-27, each with the evidence)

| Register | Scripted, login-free, captcha-free? | Evidence |
|---|---|---|
| Accredia management-system DB (`services.accredia.it/ppsearch/accredia_companymask_remote.jsp`) | **No** | The search form carries a Google reCAPTCHA widget (`g-recaptcha-response` field, `grecaptcha.getResponse()` gate in `addPercent()`); a GET with search params returns the empty mask. |
| IAF CertSearch (`iafcertsearch.org`) | **No** | JavaScript single-page app; the same ~15 KB shell is returned for any search URL; no server-rendered results. |
| EU NANDO (`ec.europa.eu/growth/tools-databases/nando`) | **No** | Migrated to the JS SPA `webgate.ec.europa.eu/single-market-compliance-space`; ColdFusion `fuseaction` URLs now return the shell only. |
| ASME certificate-holder search (`certificateholder.asme.org`) | **No (from here)** | TLS connection fails from the crawler environment; not reachable for scripted lookup. |
| National Board (`nationalboard.org`) | **No** | ASP.NET WebForms search (`__VIEWSTATE`/`__EVENTVALIDATION` POST); `SearchResults.aspx?q=` does not run a real query. |
| Achilles | **No** | Paywalled. Per the roadmap: accept the certificate PDFs the company publishes, which the collector does (`Cert_Repro_Silver_EN.pdf` matched by file name; the ASCO quote "ACHILLES Middle East and Africa" is page-text grounded). |
| Company site + published certificate PDFs | **Yes** | The collector; this is what the golden facts themselves cite. |

Conclusion: today **no register upgrade to grade A is feasible** from this environment; the collector records grade-B claims with `verified=False` and a note pointing here. The upgrade path (paid API, browser worker for reCAPTCHA-protected forms, or a manual verification step) is a data/decision change, not a schema change.

## Decisions taken and why

- No `gg_input` / `gg_approval` items were attached to this ticket; nothing was asked or assumed.
- File-name-derived facts only with a text quote (never the href as quote): the ledger's grounding gate is the ticket's own rule, and my first draft violated it — caught by the unit test `test_every_fact_quote_grounded_and_valid`.
- Group-site redirect treated as the company's own presentation (grade B, not C): a controlled subsidiary's certifications are published by the group; Corrada's golden facts cite eglagroup.com the same way.
- No `certifications.register_status` ledger fact: my first draft emitted one with a synthesized quote that no page contains — that is a fabricated quote under rule 2, so it was removed; infeasibility lives in this note and in each fact's `notes` field.

## Not done / open points

- Register verification (grade A) is **not feasible** today (see table). A paid API or a browser-based worker could unlock Accredia/IAF CertSearch; that is a new ticket, not silent scope creep.
- OCR fallback for scanned certificate PDFs (ASCO's National Board registration PDF is image-only): the collector reports it honestly instead. Belongs with I11 (document reader, OCR fallback).
- The `3-A` soft case (product-line mention vs attestation) shows the scheme patterns could be tightened with claim-vs-mention classification; left as-is because precision already exceeds the bar and over-filtering risks false absences.
