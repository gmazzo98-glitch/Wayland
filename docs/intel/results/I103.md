# I104 — Search reliability (partial)

## What I built

`SearchClient.search()` now returns a list-compatible response with per-provider health. HTTP failures, connection errors and missing provider credentials are reported without exposing request URLs or keys. Responses with provider errors are not cached as successful empty searches. Existing consumers can still iterate over the results.

Continuation: provider errors are also logged for existing consumers; Google News items are returned only when the HTTP redirect resolves to a publisher, and unresolved redirects report a provider failure. A SQLite-backed local host throttle coordinates GDELT requests across processes at 5.1-second intervals and applies a shared backoff to 429 and plain-text throttling responses.

## Verified live

The focused recorded-response suite passed (8 tests). A bounded ownership query returned SEC filing links; DuckDuckGo reported `ConnectTimeout`, GDELT `ReadTimeout`, and Google News and SEC reported successful responses. This is not an audit that the returned filings substantiate the ownership facts.

The required full suite returned 1167 passed, 12 skipped, 3 failed: the known Streamlit login timeout, status-file point ordering, and stale worker bundle tests.

Continuation: 13 focused search tests pass, including two independent processes sharing a throttle; 71 search/people/events/ownership tests passed before the last added test. The full suite returned 1172 passed, 12 skipped, 3 failed (login timeout, status point ordering and stale worker bundle). A bounded live ASCO ownership search reported DuckDuckGo `ConnectTimeout`, GDELT `ReadTimeout`, and returned two SEC filings. The first filing text mentions both Mott and ASCO Filtri (ASCO appears in its subsidiary list); those mentions alone do not independently prove their direct ownership relationship. Google News reported a successful empty response, not a verified publisher result.

## Decisions taken and why

Preserve list compatibility and attach `provider_health` to the response so existing collectors keep working while callers can distinguish errors from genuinely empty results. Error messages omit URLs and exception text, which may contain credentials.

## Not done / open points

Collectors must explicitly consume `provider_health`; existing consumers can still treat an empty response as no results despite the warnings. Google News redirects that do not resolve through normal HTTP remain unusable and are reported as errors. The throttle coordinates only processes on the same host, not separate machines sharing an IP. A verified reliable general-purpose search provider, live direct-ownership evidence, and full ticket acceptance remain unfinished. No keyed provider was enabled or purchased.
