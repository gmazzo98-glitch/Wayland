## 1. What I built

I implemented the deep site reader subsystem consisting of:
1. **`Scraper/crawlers/deep-profile-crawler`**: Standalone TypeScript/Node crawler in `..\Scraper` package structure:
   - Breadth-first crawl prioritizing high-value company pages (about, history, products, quality/certifications, contacts, downloads, legal).
   - Domain isolation ensuring external links (social media, partners) are ignored while subdomains/relative paths are normalized.
   - Comprehensive document inventory detection collecting all `.pdf`, `.docx`, `.xlsx` file links with title/type classification (`certificate`, `manual`, `catalog`, `report`, `other`).
   - Structural text extraction with verbatim quote grounding.
2. **`scrapers/deep_profile_crawler.py`**: Python wrapper for local invocation and remote worker task execution with timeout management and output contract validation.
3. **`intel/collectors/deep_site.py`**: Official Vienna collector registered under name `deep-site`:
   - Emits facts for categories: `identity.`, `contact.`, `events.`, `products.`, `locations.`, `documents.`, `ownership.`, `certifications.`.
   - General regex and DOM extraction for Italian corporate identity (Partita IVA, REA, share capital, registered offices, switchboard, PEC, generic contact emails).
   - Milestones and corporate history timeline extraction.
   - Plant openings and automated production facility expansion detection.
   - Multi-line application/market sector inventory extraction.
   - Verified quote enforcement: every fact quote is bounded and strictly verified via `intel.ledger.quote_in_text()` against the exact fetched page text.
   - Explicit `checked_absent` reporting for keys investigated but absent.
4. **`tests/test_intel_deep_site.py`**: Comprehensive offline unit test suite with recorded HTML fixtures:
   - Zero network dependency.
   - Tests document classification, URL categorization, link discovery, safe quote bounding, multi-category profile extraction, quote grounding assertions, and confirmed absence (`checked_absent`) handling.

## 4. Decisions taken and why

1. **Exact Substring Span Slicing for Safe Quotes**: Rather than attempting fuzzy string reconstruction or paraphrase trimming, `_safe_quote()` locates the match in `text` and expands outward to sentence or line boundaries while slicing strictly from `text`. This ensures `quote_in_text(ev.quote, text)` evaluates to `True` without relying on model-inferred summaries.
2. **Word Boundaries on Acronyms (`\bPED\b`, `\bASME\b`)**: Live testing on Bertazzon caught an edge-case where `ped` matched `pederivastudio`. Adding word boundaries eliminated the false positive immediately.
3. **Multi-line Application Block Detection**: Product cards and industry lists on machinery sites frequently place target industries (`Oil & Gas`, `Water Treatment`, `Pharma`) on consecutive lines rather than in a single prose sentence. Recognizing multi-line application blocks captured comprehensive portfolio data for ASCO while avoiding fragmented one-line hits.
4. **Milestone Aggregation for Events Timeline**: Company timeline pages often list milestones across several bullet points. Aggregating milestone snippets into the fact value while quoting the primary milestone verbatim allows both search engines and the gap scorer to observe multi-entity developments (such as foreign branch inaugurations).
