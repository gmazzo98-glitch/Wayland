# I05 Results: Web research layer (search, hardened fetch, readability, query planner)

*Completed 2026-10-27 by agent antigravity-e2f4*

## What I built

- `intel/search.py`: polite, pluggable public-web search client (`SearchClient`).
  - Pluggable search providers: free DuckDuckGo HTML, Google News RSS, GDELT DOC, and SEC EDGAR full-text search.
  - Optional keyed provider hooks (Brave, Serper, Tavily, SerpAPI) using standard environment variables, opt-in only.
  - Real SEC EDGAR URL reconstruction: turns SEC CIK and accession numbers (`adsh`) into live, official SEC filing URLs (`https://www.sec.gov/Archives/edgar/data/...`).
  - Thread-safe domain rate limiting (`threading.Lock` + delay tracking).
  - Canonical URL deduplication and aggregator blocking (Kompass, Pagine Gialle, social media).
  - On-disk response caching with configurable TTL.
- `intel/queryplan.py`: deterministic multilingual query generation (`build_query_pack`, `queries_for`).
  - Topics: ownership, people, events, certifications, awards, tenders, hiring.
  - Multilingual support: Italian, English, and German term packs.
  - Legal name variants (`S.p.A.`, `SpA`, `S.r.l.`, `Srl`, brand tokens) and VAT suffixing.
- `intel/fetch.py`: hardened page fetcher (`PoliteFetcher`).
  - Disk page caching with ETag (`If-None-Match`) and `If-Modified-Since` 304 handling.
  - Charset and encoding detection (`apparent_encoding` with UTF-8 fallback).
  - Optional headless Playwright browser rendering fallback for client-rendered SPA / thin pages.
  - Thread-safe per-domain delay enforcement and robots.txt compliance.
- `tests/test_intel_search.py` & `tests/test_intel_fetch.py`: comprehensive offline test suite covering query variants, provider parsing, deduplication, blocked domains, disk caching, politeness delay enforcement, and SEC EDGAR URL construction.
- `requirements.txt`: explicit dependency on `beautifulsoup4`.

## Decisions taken and why

1. **Free-First Pluggable Architecture**: Free sources (Google News, SEC EDGAR, GDELT, DDG) operate out of the box with zero key configuration. Keyed providers (Brave, Serper, Tavily) are supported as drop-ins without altering collector code.
2. **SEC Filing URL Normalization**: Resolved the issue where EFTS returns hits without URLs by programmatically assembling standard EDGAR Archive URLs from `cik` and `adsh`.
3. **Thread Safety for Politeness**: Both `PoliteFetcher` and `SearchClient` use reentrant/threading locks around timestamp comparisons to ensure multi-threaded execution never violates host delay windows.
