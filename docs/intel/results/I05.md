# I05 — Web research layer

## What I built

- `intel/search.py`: free DuckDuckGo HTML, Google News RSS, GDELT DOC and SEC EDGAR providers; optional keyed hooks; canonical URL deduplication, blocked-domain filtering, spacing and JSON caching.
- `intel/queryplan.py`: deterministic Italian, English and German packs for ownership, people, events, certifications, awards, tenders and hiring, with legal-name variants and VAT where available.
- `intel/fetch.py`: disk page cache, charset detection, optional browser rendering for thin JavaScript pages, robots-aware rate limiting, headers and grounded page text. `beautifulsoup4` is now an explicit dependency; Playwright remains optional.
- Offline tests cover query variants, provider parsing/deduplication, blocked domains and fetch caching.

## Verified live

- ASCO FILTRI S.P.A. was tested with free providers. DuckDuckGo returned zero for the combined ownership query (a provider limitation). Separate Google News searches returned 3 results for `ASCO Filtri Mott`, 1 for `ASCO Filtri IDEX`, and 1 for `ASCO Filtri Red-Fish`. GDELT returned HTTP 429 after another request, consistent with its documented five-second limit. SEC returned two public Exhibit 21 hits but without URLs, so they are excluded from ledger-ready results.
- Three additional roster-company checks were not run: sending names read from the private roster to an external search provider requires explicit authorization. No private roster names were exported.

## Golden score before / after

Not run: I05 is the search foundation and does not itself emit ledger facts.

## Decisions taken and why

- Free providers are the default; keyed providers are opt-in by environment name only.
- Directory aggregators including Kompass and Pagine Gialle are filtered from research results.
- Search results remain snippets and URLs. Collectors must fetch and quote-ground pages through `PoliteFetcher` before creating facts.

## What the next agent must know

Use `SearchClient.search(...)` for discovery and `PoliteFetcher.fetch(...)` for evidence pages. Provider failures are non-fatal and must remain visible in the run trace, never become invented facts.
