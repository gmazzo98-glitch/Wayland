## Verified live (probes only, no code)

From this sandbox, on 2026-10-27:

* EPO OPS without credentials: `GET ops.epo.org/3.2/rest-services/published-data/search` returns
  HTTP 403 "rejected due to the violation of Fair Use policy". No `EPO_OPS_CONSUMER_KEY/SECRET`
  is available in this environment (no `.env` in the worktree), and OPS has no anonymous tier;
  the adapter's own docstring says it falls back to simulated values without the key.
* Espacenet (worldwide.espacenet.com): every endpoint tried (classic UI, REST search,
  `/patent/search`) returns 403 with an empty body regardless of User-Agent: the sandbox egress
  IP is blocked by the EPO edge, not something fixable in code.
* register.epo.org: 403 likewise.
* Google Patents `/xhr/query`: 200 but a 146-byte JS-required stub.
* WIPO PATENTSCOPE: reachable, but the results page is a JSF application; a full ViewState
  POST reproduces the form with the query echoed and NO result rows: the search executes only
  in browser JS (search.jsf 200, result.jsf 200, POST with viewstate 200, zero W hits).

Adapter code review (no changes made, outside the claim once blocked):

* `adapters/epo_ops.py` is already substantially hardened: process-wide token cache with lock
  (its docstring attributes the 2026-09-22 634/811 failure run to the token-endpoint throttle),
  fair-use pacing (`SEARCH_INTERVAL_SECONDS` 6.5), throttling-header response, rejection circuit
  breaker with weekly/hourly backoff, 401 token invalidation, Retry-After handling. The 73%
  error rate in the roadmap's source_health snapshot predates or coexists with these; the real
  cause (quota vs IP block vs token throttle) cannot be distinguished without credentials and
  a non-blocked egress, because this sandbox gets 403 from every EPO property.

## Decisions taken and why

* Blocked rather than building unverified collectors: the acceptance is "error rate under 5%
  over 100 companies; ASCO's records agree with Espacenet by hand". Neither can be measured
  or attempted from this environment. Writing an `ip.*` collector whose only reachable sources
  are none would produce a collector that has never seen a real patent page, exactly what the
  ground rules refuse.
* Released with no files touched, so the ticket is clean for the next agent.
