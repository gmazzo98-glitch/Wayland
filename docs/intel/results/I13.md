# I13 Results: Corporate events timeline (deals, plants, subsidiaries, leadership changes, awards)

*Completed 2026-10-27 by agent antigravity-8c2f*

## What I built

- `intel/events.py`: Shared corporate events taxonomy, data models, and timeline merging engine.
  - Event model (`CorporateEvent`): typed event representation mapped to `diagnosis.contracts.TRIGGER_KINDS` (`ownership_change`, `investment_announced`, `expansion`, `leadership_change`, `partnership`, `certification`, `other`). Stores title, description, ISO date/year, participating parties, financial amounts, sources, quotes, and conflicting source records.
  - Event deduplication and multi-source merging (`merge_events`): combines reports of the same event across outlets into one event with multiple sources, quotes, and parties.
  - Date conflict recording: detects disagreements in dates across sources (e.g. Mott deal dated 13 January 2022 by PR Newswire vs 2021 on Mott's own website) and records them explicitly in `conflicts` rather than overwriting.
  - Chronological ordering: sorts merged events from earliest to latest.
- `intel/collectors/events.py`: Collector exposing `COLLECTOR = Collector(name="events", ticket="I13")`.
  - Harvesters:
    1. Own-site history & timeline pages (`/Home/Company`, `/chi-siamo`, `/about-us`, `/history`): extracts milestone years, foundations, foreign branches, headquarters moves, and automated manufacturing facilities.
    2. Deal press & M&A coverage (BeBeez, PR Newswire, Mott Corporation, sector press): extracts private equity buyouts, acquisitions, reinvesting management, financial amounts, and leadership transitions.
  - Emits specific ledger facts: `events.timeline`, `events.ownership_change`, `events.expansion`, `events.leadership_change`, `events.partnership`, and `ownership.deal`.
  - Verbatim quote grounding: verifies every event quote against page text using `quote_in_text`.
  - Strict entity isolation (`_entity_matches`): ensures zero cross-company leakage from general M&A articles.
- `tests/test_intel_events.py`: Offline unit test suite (5 tests) covering event normalization, year parsing, timeline deduplication and date conflict detection, collector execution with recorded pages, and confirmed absence recording.

## Decisions taken and why

1. **TRIGGER_KINDS Alignment**: Structured all event types according to the canonical `diagnosis.contracts.TRIGGER_KINDS` enum, enabling diagnosis trigger engines (D16, D17) to consume `events.*` facts directly without transformation.
2. **Recording Conflicts without Overwriting**: In accordance with project ground rules, when two authoritative sources provide conflicting dates (e.g. PR Newswire specifying 13 January 2022 while Mott's own website references 2021), both values and URLs are recorded in the `conflicts` array rather than prematurely picking one.
3. **Confirmed Absence vs Missing**: When a company's web presence yields no verifiable corporate events, the collector explicitly records `checked_absent=["events.timeline"]` rather than leaving the field missing.
