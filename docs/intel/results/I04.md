## Decisions taken and why
* **Task-based routing with tier preferences**: `triage` prioritises free/cheap models to protect user budgets during high-volume page classification; `synthesize` routes to higher tier reasoning models (e.g. Mistral/Claude/GPT-4o).
* **OpenAI-compatible protocol standard**: Standardised on OpenAI-compatible `/chat/completions` JSON schema because Groq, Mistral, Google AI Studio OpenAI endpoint, Cerebras, OpenRouter, and Ollama all implement it, minimizing provider-specific branching.
* **Non-destructive repair before retry**: Strip markdown fences and repair common syntax defects (trailing commas, Python booleans) before spending an extra LLM call on a retry. Only trigger a retry prompt if regex normalisation cannot parse the JSON.
* **Worker bundle rebuild**: Did NOT rebuild `worker_dist/vienna-crawler-bundle.zip` or touch `worker_shim/app` in accordance with ticket rules (Wave release captain ticket I90 handles bundle rebuilds).
